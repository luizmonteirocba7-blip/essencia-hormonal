# Essência Hormonal

Cópia de trabalho do site Essência Hormonal.

## Página publicada

https://luizmonteirocba7-blip.github.io/essencia-hormonal/

## Estrutura

- index.html: conteúdo e estrutura da página.
- styles.css: identidade visual e layout responsivo.
- motion.js: navegação móvel, vídeos e animações de entrada.
- assets/: fotos, logotipo, capas e depoimentos em vídeo.

## Visualização local

Abra index.html no navegador ou use um servidor estático local apontando para esta pasta.

Os botões de agendamento levam ao WhatsApp público da clínica. Os códigos externos de publicidade e métricas foram removidos da cópia.
