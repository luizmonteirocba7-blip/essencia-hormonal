# Essência Hormonal

Cópia local de trabalho da página pública https://essenciahormonal.com.br/.

## Estrutura

- `index.html`: conteúdo e estrutura da página.
- `styles.css`: estilos extraídos para facilitar a edição visual.
- `assets/`: fotos, logotipo, capas e depoimentos em vídeo usados pela página.

## Visualização local

Abra `index.html` no navegador ou use qualquer servidor estático local apontando para esta pasta.

Os botões de agendamento ainda levam ao WhatsApp público da clínica. Os códigos externos de publicidade e métricas foram removidos da cópia.
